# Sina Mehboodi — GitHub Pages Portfolio

A single-page professional website designed as a broad portfolio rather than a job-specific CV.

## Files

- `index.html` — complete website with embedded CSS and JavaScript
- `profile.png` — add your professional photo using this exact filename
- `Sina_Mehboodi_CV.pdf` — add the downloadable CV using this exact filename

The website still works without the photo; it displays the initials `SM` as a fallback. The CV button requires the PDF file to be added.

## Publish with GitHub Pages

1. Create a repository named `SinaMehboodi.github.io` for the main user site, or use another repository for a project site.
2. Upload `index.html`, `profile.png`, and `Sina_Mehboodi_CV.pdf` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder, then save.

## Before publishing

Review these items in `index.html`:

- Current role wording and start date
- German-language level
- Phone number and contact links
- Publication details
- Google Analytics ID and whether you want analytics enabled
- CV filename if your PDF uses another name

## Design notes

- Responsive layout for desktop and mobile
- General positioning across physics, data, technology, and solution consulting
- Skills are divided into demonstrated experience and developing knowledge
- Project section highlights `drlib`
- No external CSS or JavaScript dependencies
